1. Maquetación ARF-GRID (Mobile-First):

   - Queda estrictamente PROHIBIDO usar anchos o altos fijos en píxeles (px) para elementos hijos.
   - Usar unidades relativas (rem, %, vw), max-width en desktop y aspect-ratio para evitar CLS.
2. Higiene de Estilos ('ORO'):
   - Queda estrictamente PROHIBIDO generar estilos en línea (style="") en el marcado HTML.
   - Todo el CSS debe escribirse en la hoja de estilos principal (assets/css/main.css).
   - Queda estrictamente PROHIBIDO el uso de !important. Los conflictos se resuelven en la raíz
     de la cascada respetando la especificidad de los selectores.
3. Consistencia UI y Tokens:
   - Mantén intactos los selectores y la lógica de menús hamburguesa y barras ya aprobadas.
   - Utiliza exclusivamente las variables CSS de paleta de color definidas en :root.

   - Toda sección de catálogo, banners o publicaciones debe estar estructurada como componente
     iterable limpio, lista para ser poblada por bucles de servidor o llamadas fetch().

   - Simula la persistencia mediante archivos locales mock-data.json. No intentes escribir PHP.
